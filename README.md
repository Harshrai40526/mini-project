A responsive Weather Application built using React.js and Material UI that displays real-time weather information like temperature, humidity, pressure, and weather conditions.

🚀 Features

🌡️ Current Temperature

🤔 Feels Like Temperature

💧 Humidity

📊 Pressure

🌍 City-based Weather Search

🎨 Dynamic UI styling based on temperature

📱 Fully Responsive Design

⚡ Fast and Lightweight


🛠️ Tech Stack

⚛️ React.js

🎨 Material UI

🌐 OpenWeather API
